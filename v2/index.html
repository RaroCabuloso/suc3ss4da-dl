A documentação pública confirma os nomes das categorias e várias rotas específicas. Quando uma categoria não revela a rota diretamente no HTML textual da docs, o painel não inventa parâmetros.

API KEY

A chave fica somente no localStorage deste navegador. Não existe uma chave privada embutida neste HTML.
LOCAL
O botão de validação usa uma chamada real ao endpoint ytaudio2. Ele considera 401/403 como rejeição; respostas 200/206 indicam que a chave foi aceita pelo endpoint, embora o navegador ainda possa bloquear por CORS.

FIXA
